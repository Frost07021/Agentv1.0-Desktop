# Security Policy

## 敏感配置

- 不要提交 `.env`、真实模型 URL、API Key、用户历史、上传媒体和模型分析结果。
- 仓库只提供 `.env.example`，所有值均为占位符。
- `runtime/`、`output/`、`.runtime/` 和 `.venv/` 已加入忽略规则。
- 如果密钥曾出现在聊天、日志、Issue 或提交历史中，应立即轮换。

## 用户与医疗数据

本地历史可能包含用户对话、宠物档案和检测结果。提交前运行 `git status --ignored`，确认 `runtime/` 没有进入暂存区。

AI 输出仅供宠物健康观察参考，不构成兽医诊断或处方。

## 报告问题

请通过私有安全渠道报告凭证泄露、跨会话访问、媒体越权或医疗安全问题，不要在公开 Issue 中附上真实用户数据。
